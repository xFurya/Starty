# Фигурное катание — календарь стартов

Приложение для Android, iPhone, Windows и macOS (Flutter, папка `app/`) и ICS-лента: российские
старты и международные с россиянами и белорусами. Время везде московское. Расписание
обновляется само в 09:00 и 15:00 МСК.

- Скачать: https://xfurya.github.io/Starty/ (Android — .apk, iPhone — через SideStore)
- Расписание, которое читает приложение: `…/Starty/data/events.json`
- Лента для календаря: `…/Starty/calendar.ics`

## Сборка приложения

- Android: `cd app && flutter build apk --release --target-platform android-arm64
  --dart-define=BUILD=<номер>` — подпись ключом из `android/key.properties`
  (ключа в этом репозитории нет). Готовый файл кладётся в `site/app/Starty.apk`,
  номер — в `site/app/version.json`: по нему приложение предлагает обновиться.
- iPhone: `.github/workflows/app-ios.yml` собирает `.ipa` без подписи на macOS
  при каждом изменении `app/` и кладёт её в `site/app/Starty.ipa`; SideStore
  берёт её по `site/app/sidestore.json`.

- Windows и macOS: `.github/workflows/app-desktop.yml` собирает zip (Windows — папка с
  `starty.exe`, macOS — `Starty.app` с подписью ad-hoc) после каждого выпуска
  (`tools/release.sh`), кладёт архивы во вкладку Releases (`app-v<версия>`), а адрес,
  размер и sha256 — в `site/app/latest.json`. Приложение обновляет себя само
  (`app/lib/desktop_updater.dart`): скачивает архив, сверяет sha256 и при закрытии
  запускает короткий скрипт, который заменяет файлы. Ручной запуск воркфлоу — пробная
  сборка без выкладки.
- Уведомления на компьютере: macOS — как на iPhone (планировщик системы); Windows —
  запланированные тосты системы, но снять поставленное без пакета MSIX нельзя, поэтому
  приложение помнит уже поставленное. Фоновых задач у обеих систем для Flutter нет:
  расписание обновляется, пока приложение открыто (раз в 3 часа и при открытии).
- Протокол турнира: на macOS — во встроенном окне, на Windows — в браузере системы.

## Что попадает в календарь

- Российские турниры из календаря ФФККР — все, уровня МС и КМС (разряды, детские
  и синхронное катание не берутся).
- Международные — только сегменты, где выступают россияне или белорусы: `RUS` или
  `AIN2` (нейтральные россияне), `BLR` или `AIN1` (белорусы).
- Одно событие = один сегмент: «ЮГП России «Мемориал Горшкова» — девушки ПП».
- На российских стартах в «Россияне и белорусы» попадают юниоры из списка в
  `scraper/config.json` (`watchlist`).
- Турниры, у которых ещё нет расписания по сегментам, в календарь не попадают —
  в приложении они в блоке «Скоро, без расписания».
- Когда сегмент прошёл, в событии — первая тройка (`podium`), места россиян и белорусов
  (`place`); у последнего сегмента вида — первая тройка турнира (`total`) и
  итоговые места россиян и белорусов (`final`). Если россияне и белорусы не прошли в последний сегмент, итог
  турнира — у их последнего старта.

## Уведомления

По умолчанию — о каждом старте, за 15 минут до начала: «17:30 · женщины ПП»,
ниже турнир, россияне и белорусы со временем выхода и трансляция. В настройках приложения —
правила: виды, уровень, российские и международные, короткая и произвольная,
ночные старты, за сколько минут; отдельно — выход россиян и белорусов (по умолчанию выключен).
Отдельный старт включается и выключается в его карточке. На Android приложение
раз в 3 часа подтягивает расписание и переставляет уведомления само.

## Откуда данные

| Источник | Что берём |
|---|---|
| fsrussia.ru/calendar | список российских турниров, даты, место |
| страницы турниров ФФККР | PDF-расписание, табло, ссылки на трансляции |
| табло Swiss Timing (ФФККР, ISU, организаторы) | время сегментов, стартовые листы, PDF «время выхода» |
| front-api.isu.org | расписание и заявки турниров ISU до появления табло |
| goldenskate.com (API календаря) | прочие международные турниры и ссылки на их табло |
| fsrussia.ru/sbornaya | русские написания имён сборников, фото |
| протоколы Swiss Timing (SEGnnn, CATnnnRS) | первая тройка сегмента и турнира, места россиян и белорусов |
| портреты ISU | фото иностранцев и россиян без фото в сборной |

Фото уменьшаются до квадрата 256 px и лежат в `site/photos` (нужен Pillow:
`apt install python3-pil`; без него в данных остаётся адрес оригинала).

Время из протоколов переводится в МСК по смещению, которое табло указывает
само («Local Time, UTC +05:00»); для PDF ФФККР — по городу (`ru_tz` в конфиге).

## Как устроено обновление

`.github/workflows/update.yml` по расписанию (06:00 и 12:00 UTC) запускает
`python3 -m scraper.build`, сохраняет данные в `main` и выкладывает папку
`site/` в ветку `gh-pages` — её и показывает GitHub Pages.

Если источник не ответил, его старты берутся из прошлого успешного сбора; если
будущих стартов вдруг стало вдвое меньше — данные не перезаписываются вовсе.
Приложение пишет внизу, когда расписание обновлялось, и работает без сети по
последней копии.

## Если что-то сломалось

1. Вкладка **Actions** → «Обновление расписания» → последний запуск. Красный —
   откройте шаг «Собрать расписание», в конце лога список ошибок.
2. Перезапуск руками: Actions → «Обновление расписания» → **Run workflow**.
3. Не тот канал трансляции или имя — правится в `scraper/config.json`
   (`broadcast_overrides`, `aliases`), коммит в `main` сам перезапустит сборку.

## Локально

    sudo apt install poppler-utils python3-pil
    python3 -m scraper.build           # данные в site/
    cd site && python3 -m http.server  # http://localhost:8000
