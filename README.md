# Старты — календарь стартов по фигурному катанию

Приложение (PWA) и ICS-лента: российские старты и международные с нашими.
Время везде московское. Расписание обновляется само в 09:00 и 15:00 МСК.

- Приложение: `https://<владелец>.github.io/starty/`
- Лента для календаря: `https://<владелец>.github.io/starty/calendar.ics`

## Что попадает в календарь

- Российские турниры из календаря ФФККР — все, уровня МС и КМС (разряды, детские
  и синхронное катание не берутся).
- Международные — только сегменты, где выступают наши: `RUS` или `AIN2`
  (нейтральные россияне). `AIN1` — белорусы, их не считаем.
- Одно событие = один сегмент: «ЮГП России «Мемориал Горшкова» — девушки ПП».
- На российских стартах в «Наши» попадают юниоры из списка в
  `scraper/config.json` (`watchlist`).
- Турниры, у которых ещё нет расписания по сегментам, в календарь не попадают —
  в приложении они в блоке «Скоро, без расписания».

## Откуда данные

| Источник | Что берём |
|---|---|
| fsrussia.ru/calendar | список российских турниров, даты, место |
| страницы турниров ФФККР | PDF-расписание, табло, ссылки на трансляции |
| табло Swiss Timing (ФФККР, ISU, организаторы) | время сегментов, стартовые листы, PDF «время выхода» |
| front-api.isu.org | расписание и заявки турниров ISU до появления табло |
| goldenskate.com (API календаря) | прочие международные турниры и ссылки на их табло |
| fsrussia.ru/sbornaya | русские написания имён сборников |

Время из протоколов переводится в МСК по смещению, которое табло указывает
само («Local Time, UTC +05:00»); для PDF ФФККР — по городу (`ru_tz` в конфиге).

## Как устроено обновление

`.github/workflows/update.yml` по расписанию (06:00 и 12:00 UTC) запускает
`python3 -m scraper.build`, сохраняет данные в `main` и выкладывает папку
`site/` в ветку `gh-pages` — её и показывает GitHub Pages.

Если источник не ответил, его старты берутся из прошлого успешного сбора; если
будущих стартов вдруг стало вдвое меньше — данные не перезаписываются вовсе.
Приложение пишет внизу, когда расписание обновлялось, и работает без сети по
последней копии.

## Если что-то сломалось

1. Вкладка **Actions** → «Обновление расписания» → последний запуск. Красный —
   откройте шаг «Собрать расписание», в конце лога список ошибок.
2. Перезапуск руками: Actions → «Обновление расписания» → **Run workflow**.
3. Не тот канал трансляции или имя — правится в `scraper/config.json`
   (`broadcast_overrides`, `aliases`), коммит в `main` сам перезапустит сборку.

## Локально

    sudo apt install poppler-utils
    python3 -m scraper.build           # данные в site/
    cd site && python3 -m http.server  # http://localhost:8000
