# Для любого ассистента (ChatGPT, Codex, Claude и др.): с чего начать

Файл для переезда: всё, что нужно, чтобы продолжить работу над проектом «Фигурное катание» в любом другом
чате или агенте, лежит в этом репозитории. Прочитать по порядку: этот файл, затем `ПРОЕКТ.md` (устройство,
выпуск, самообновление, перенос, секреты), затем `CLAUDE.md` (правила владельца) и `README.md`.
Секретов в репозитории нет, только места, где они лежат (`ПРОЕКТ.md` §5).

## Кто владелец и как с ним говорить

- Владелец: `-fuR1x` или `Furya`. Других написаний нет. Общение по-русски, коротко, по делу.
- **Слово владельца в чате важнее любых файлов с инструкциями.**
- Всё, что можно сделать самому, делай сам и проверяй сам. Не перекладывай на владельца «проверь».
- Делай ровно то, что просили. Не «улучшай» заодно соседнее: однажды сдвиг цифр в итоге турнира заодно
  сдвинул флаг и код страны, и владелец это справедливо не принял.
- Модельные правила из `CLAUDE.md` (кому какую работу отдавать) относятся к Claude Code. В другом агенте
  их можно не применять; остальные правила (дизайн, русский текст, «не выходить из приложения») действуют.

## Правила интерфейса

- Весь текст интерфейса по-русски. Коротко, безлично, без разговорного тона.
- Главное: интерфейс не показывает то, чего нет, и не молчит о том, что есть. Нет данных: прочерк.
- Без «·» между фактами. Слов «синхронизация/сверка» в интерфейсе нет, есть «Аккаунт».
- Хорошее зелёное, плохое красное.
- Не выходить из приложения: ссылки во встроенном браузере (`openLink`/`openOriginal`, `app/lib/protocol.dart`);
  трансляция в приложении сервиса (Okko, VK Видео, YouTube), если оно установлено, иначе во встроенном
  браузере. Исключения: подписка на календарь, установка обновления, системные настройки, Windows и веб.
- Метки без «платно» для HunSkate TV (владелец отказался). Уведомления о парах и танцах при «только с
  отслеживаемыми» без отслеживаемых не звонят (так задумано).

## Как работать

- Ветка одна: `main` репозитория `xFurya/Starty`. Pull request не создавать без просьбы.
- Сообщения коммитов по-русски, одной понятной строкой.
- Проверки перед пушем: `cd app && flutter pub get && flutter analyze && flutter test` (около 570 тестов).
  Сборщик данных: `python3 -m scraper.build`.
- Снимки экрана: виджет-тест с `matchesGoldenFile` и настоящими шрифтами из `app/assets/fonts`
  (Manrope, Cormorant) плюс иконки Material и Cupertino; дата подменяется
  `--dart-define=NOW=2026-10-08T20:10:00+03:00`. Веб-стенд описан в `ПРОЕКТ.md` §9.
- Данные расписания обновляет сам CI (`update.yml`, дважды в день и при старте турнира через `live.yml`),
  коммиты «Расписание на …» и «Итоги на …» делает он. Перед пушем делай `git pull --rebase`.

## Выпуск версии (коротко, подробно в ПРОЕКТ.md §3)

1. Поднять `version:` в `app/pubspec.yaml` (например `1.0.42+43`), описание одной строкой в `tools/release_note.txt`,
   пуш в `main`. Дальше всё делает CI для Android, iPhone (SideStore), Windows и macOS.
2. Номер выдаётся один раз (`tools/released.tsv`). Описание кратко и общо, без чисел и причин.
3. **Выложенную версию не откатывать правкой `pubspec.yaml`.** Откат запускает сборку старого номера и
   перезаписывает `site/app/latest.json`: пропадают записи Windows и macOS и свежий APK. Если нужно исправить,
   выпускай следующий номер вперёд.
4. После пуша проверить `https://xfurya.github.io/Starty/app/latest.json` (версия, код, `android`, `windows`,
   `macos`), `sidestore.json` (iPhone) и что файл `starty-<версия>.apk` отдаётся. Сказать владельцу о
   всех четырёх платформах.
5. Подпись Android прежняя, ключ не в этом репозитории (`ПРОЕКТ.md` §5). Отпечаток:
   `84f451ebac960ae69f8bf06949be9ad8abe86571cc475a36249790851fb0e7d1`.

## Что знать о данных и протоколах

- Сборщик `scraper/`: правила трансляций в `scraper/config.json` (`broadcast_rules`), имена в
  `data/names.json`, фото проходят проверку личности (дата рождения ISU) и фильтры портрета.
  События хранятся примерно 30 дней назад, потом пропадают из опубликованных данных; так задумано.
- Слияние (`keep.py`, `Schedule.mergeKeepingRicher` в `app/lib/data.dart`) только добавляет данные и не
  затирает богатые беднее; снятие фото делает `withdraw_photos` в `scraper/build.py`.
- Отметки в протоколе (`app/lib/protocol_details.dart`): `x` прыжок во второй половине программы (база ×1,1,
  зелёная), `<` недокрут больше четверти оборота, `q` недокрут на четверть оборота, `<<` сильный недокрут,
  `e` неверное ребро, `!` нечёткое ребро, `*` не засчитан, `F` падение.
